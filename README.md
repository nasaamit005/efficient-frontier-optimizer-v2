## Stage 1 — Portfolio Optimization

Analyzes the efficient frontier, risk-return trade-offs, optimal asset allocations, and market/asset diagnostics.

## Stage 2 — Portfolio Robustness

Examines out-of-sample performance, rolling portfolio weights, bootstrap frontier estimates, and covariance-estimation methods.

## Research Considerations

Results depend on the data sample, expected-return estimates, covariance estimates, constraints, and risk-free-rate assumptions. Further validation should examine transaction costs, turnover, sensitivity to assumptions, and estimation uncertainty.

Historical performance does not guarantee future results.
