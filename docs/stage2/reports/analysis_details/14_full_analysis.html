14. Bootstrap / Resampled Efficient Frontier

Objective

Shows variation in estimated frontier points under resampled training returns.

How it is constructed

Aligned circular moving blocks are sampled jointly across assets; each replicate re-estimates mean/covariance and feasible frontier points.

Why it matters

This analysis addresses estimation risk and the instability of optimized portfolio decisions. Its purpose is to expose sensitivity and validation gaps, not to select a portfolio solely from historical performance.

Core formulas

Annualized arithmetic mean: 252 × mean(daily returns). Annualized volatility: sqrt(252) × sample standard deviation(daily returns). Sharpe ratio: (annualized mean − annual risk-free rate) / annualized volatility.

Portfolio variance: wᵀΣw; portfolio expected return: wᵀμ; fully invested constraint: Σwᵢ = 1; long-only bound: 0 ≤ wᵢ ≤ 0.40.

Actual outputs

See the corresponding CSV file(s) in data/processed, the interactive chart, and the Excel workbook. Findings should be quoted from these calculated values rather than inferred from chart appearance.

Assumptions and limitations

Block length and replicate count are assumptions; use more replications and sensitivity tests for a research paper.

All outputs are sensitive to asset universe, dates, annualization, risk-free rate, window length, weight caps, and the chosen resampling procedure.
